What is the CSS Box Model?

The CSS Box Model describes how every HTML element is represented as a rectangular box.

It consists of content, padding, border and margin.

Box Model Components

Content

This is the content area of the box.

Padding

Padding creates space between content and the border.

Border

Border surrounds the padding and content.
