Introduction to CSS & Selectors

Learning the fundamentals of CSS styling

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML webpages.

CSS controls colors, backgrounds, fonts, spacing, alignment and the overall appearance of a webpage.

CSS Selectors

Class selectors are used to style multiple HTML elements.

The class selector is represented using a dot (.).

ID Selector

An ID selector is used to style a specific HTML element.

The ID selector is represented using the hash symbol (#).

Colors & Backgrounds

CSS allows us to change the text color and background color of HTML elements.

CSS makes webpages visually attractive.
