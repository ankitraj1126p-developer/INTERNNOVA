# InternNova Homepage Redesign — Ankit Raj

A React + Vite visual redesign of the InternNova homepage. The homepage structure and key content are based on the public InternNova homepage, while the theme, typography, spacing, cards, visual hierarchy, interactions and animation treatment are redesigned.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Design direction
- Dark modern EdTech / technology theme
- New typography and visual hierarchy
- Responsive desktop, tablet and mobile layout
- Animated reveal sections
- Interactive program filters
- Interactive FAQ accordion
- Modern cards, buttons and statistics

Reference: https://internnova.co.in/
